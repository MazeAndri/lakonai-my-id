# LakonAI (`lakonai.my.id`) — AI Roleplay & Story Studio

**LakonAI** ([https://lakonai.my.id](https://lakonai.my.id)) is a web-based AI character roleplay and interactive storytelling platform built for immersive, long-form stories with persistent memory and dynamic worlds.

## Key Features
- **Living Worlds (World Lite)**: Build interactive 2D zone maps, custom world clocks & calendars, and formula-driven character State trees (HP, quests, relationships, custom stats) tracked automatically by an AI Auditor.
- **Persistent Memory & Lorebooks**: Control context history with Memory Wall, chronicle summarization, and keyword-triggered Lorebooks.
- **Personas & Modular Prompts**: Create and switch between multiple user personas mid-story, and combine custom system prompts with modular sub-prompts.
- **Multi-Model & OpenAI-Compatible API**: Choose from multiple AI models with pay-as-you-go credits (*Duit*, including free daily claims) or connect your `/v1` API key directly to SillyTavern and other clients.
