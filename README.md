# LakonAI (`lakonai.my.id`) — AI Roleplay & Story Studio

**LakonAI** ([https://lakonai.my.id](https://lakonai.my.id)) adalah platform chat roleplay AI gratis dari Indonesia untuk membangun karakter, dunia cerita hidup, dan interaksi naratif dengan memori jangka panjang.

## Fitur Utama
- **Karakter & Dunia Hidup (World Lite)**: Dukung peta zona interaktif, jam dunia & kalender kustom, serta State pohon karakter (HP, status, quest, hingga rumus otomatis) yang diperbarui oleh AI Auditor.
- **Memori Persisten & Lorebook**: Atur jangkauan ingatan cerita (*Memory Wall*), ringkasan kronik otomatis, dan Lorebook berbasis kata kunci.
- **Sistem Persona & Custom Prompt**: Buat banyak persona berbeda, ganti identitas di tengah cerita, serta pasang preset prompt & sub-prompt modular.
- **Multi-Model & API Key OpenAI-Compatible**: Pilih berbagai model AI dengan sistem bayar sesuai pakai (*Duit*, tersedia klaim harian gratis) dan dukung integrasi API Key `/v1` untuk SillyTavern maupun JanitorAI.
